Bella Beauty Database Dashboard

A visual representation of the database schema defined in schema.sql.

Users

  • id: INT (PK)
  • full_name: VARCHAR
  • email: VARCHAR (UNIQUE)
  • password_hash: VARCHAR
  • shipping_address: TEXT
  • created_at: TIMESTAMP

Categories

  • id: INT (PK)
  • name: VARCHAR (UNIQUE)
  • slug: VARCHAR (UNIQUE)
  • description: TEXT

Products

  • id: INT (PK)
  • category_id: INT (FK → Categories)
  • title: VARCHAR
  • description: TEXT
  • price: DECIMAL
  • image_url: VARCHAR
  • stock_quantity: INT
  • created_at: TIMESTAMP

Product_Details

  • id: INT (PK)
  • product_id: INT (FK → Products)
  • attribute_name: VARCHAR
  • attribute_value: VARCHAR

Orders

  • id: INT (PK)
  • user_id: INT (FK → Users)
  • total_amount: DECIMAL
  • status: VARCHAR
  • shipping_address: TEXT
  • order_date: TIMESTAMP

Order_Items

  • order_id: INT (PK, FK → Orders)
  • product_id: INT (PK, FK → Products)
  • quantity: INT
  • price_per_unit: DECIMAL

Reviews

  • id: INT (PK)
  • product_id: INT (FK → Products)
  • user_id: INT (FK → Users)
  • rating: INT (1-5)
  • comment: TEXT
  • created_at: TIMESTAMP
